Introducing Regal Calendar SQL

Complete event calendar solution that displays events in a friendly and attractive way. Shows the time in which the events take place (countdown), the map, the current climate of the place, with twitter enabled and many other features.

Features

  • Visually appealing and easy to use.
  • Stores events in a MySQL or SQLite database.
  • Displays the event location via Google maps.
  • Includes editable option. You can add and delete events using the calendar.
  • Informs about the current weather in the place where the event occurs.
  • Shows time of the event and a countdown clock.
  • API returns events of the month, selected event and current date.
  • Displays inline events or via tooltips.
  • Can select any color scheme.
  • Responsive design.
  • Twitter enabled.
