Usage

Get started with database

RegalCaledarSQL stores all events in a database, either SQLite or MySQL if you prefer.

The database contains two tables, "events" and "subscriptions". Table "events" stores detailed information about the events. Table "subscriptions" contains the email and name of the person subscribed to the event.

The package contains a sample SQLite database, so you can simply start to use it, and a file *.sql to create the database for MySQL.

In order to use SQLite simply, ensure you have PHP sqlite extension. Verify the file regalcalendar.sqliteis in datasourcefolder.

Set database type to sqlite and database file path in the file php/Source/Config.php 

				
				
/* SQLite configuration */
<?php
    const DATABASE_TYPE = 'sqlite'; // database type, can be mysql or sqlite
    const DATABASE_PATH = '../datasource/regalcalendar.sqlite'; // path of SQLite database file
?>

If you are using MySQL, first run regalcalendar.sqlscript in order to create database. You can use phpmyadmin to import it.

Next specify the connection information for database and set DATABASE_TYPE to "mysql" in the file php/Source/Config.php 

				
				
/* MySQL configuration */
<?php
    const DATABASE_HOST = 'localhost'; // host name or IP address
    const DATABASE_USERNAME = 'root'; // database username
    const DATABASE_PASSWORD = ''; // database username password
    const DATABASE_NAME = 'regalcalendar'; // database name
    const DATABASE_TYPE = 'mysql'; // database type, can be mysql or sqlite
?>

Send emails

You can send reminders via email to persons that have subscribed to the events.

Set your email server data.

php/Source/Config.php 

				
				
<?php
    /* Email configuration */
    const EMAIL_SERVER = "smtp.gmail.com"; // email server, you can use your gmail account.
    const EMAIL_PORT = 465; // port
    const EMAIL_TYPE = "ssl";
    const EMAIL_USERNAME = "your@username";
    const EMAIL_PASSWORD = "password";
    const EMAIL_TEMPLATE = "Source/Templates/template.html"; // html email template file location
?>

Import *.ics calendar

You can import *.ics Google calendars to your the database directly.

Press import button, select an *.ics file. Click upload and the events will be add to the database.

Twitter configuration* (optional)

You can enable twitter in your calendar. Users can confirm their attendance to any event or comment about it.

Firstly we need to create a new twitter application in order to have the permissions to show tweets. Sign up at https://apps.twitter.com/and create a new app.

Give a name to your app, a short description and type your website. If you don't have a site yet just type any url. Accept the agreement.

You will need some information in order to connect calendar with your new application. You can set the information in the file php/Source/Config.php.

				
				
/* Config.php */
<?php
	/* Twitter configuration */
    const SEARCH_QUERY = 'your twitter user name, or search criteria'; // search criteria
    const CONSUMER_KEY = 'twitter app consumer key'; // consumer key
    const CONSUMER_SECRET = 'twitter app consumer secret'; // consumer secret
    const ACCESS_TOKEN = 'twitter app consumer accesstoken'; // access token
    const ACCESS_TOKEN_SECRET = 'twitter app consumer accesstoken secret'; // access token secret
?>

You can find the information in the tab settings

To obtain accesstoken and accesstokensecret, click on the button Create my access token

Now you have the complete information to connect calendar with your application. Just copy and paste the information.

Weather* (optional)

In order to retrieve the weather of the location of events, you need a connection to openweathermap.org API to query the weather.

You can create a free account at http://home.openweathermap.org/users/sign_up

Sign in and simply copy the API key. Paste API key to the calendar configuration.

				
<script>
  $(function() {
    $('#calendar').RegalCalendar({
	  apiKey: 'xxxxxxxxxxxxxxxxxxxxxx',
	  dayPanel: 'inline'
    });
  });
</script>

Set up calendar

Now the database is ready, you can start to use the calendar. Use the required scripts and stylesheets.

Create a empty container with class="regalcalendar"in any place of your site.

Initialize the calendar with options that you need in your project.

				
<head>
    <!-- events icons -->
    <link rel="stylesheet" href="css/font-awesome.css">
	<!-- bootstrap -->
    <link rel="stylesheet" href="css/bootstrap.min.css">
    <!-- weather icons -->
    <link rel="stylesheet" href="css/weather-icons.css">
    <!-- calendar css -->
    <link rel="stylesheet" href="css/RegalCalendar.css">
	
    <!-- Google maps library -->
    <script src="http://maps.googleapis.com/maps/api/js?sensor=false&libraries=places"></script>
    <!-- require js to load scripts -->
    <script src="js/lib/require.js"></script>
	
    <!-- initialize calendar -->
    <script>
	/* dependencies */
	requirejs.config({
		baseUrl: 'js/lib',
		paths: {
			jquery: "jquery-2.1.4.min",
			underscore: 'underscore-min'
		},
		shim: {
			'bootstrap.min': ['jquery'],
			'jquery.easing.1.3': ['jquery'],
			'jquery.iconpicker': ['jquery'],
			'jquery.timepicker': ['jquery'],
			'jquery.qtip': ['jquery'],
			'jquery.geocomplete.min': ['jquery'],
			'jquery-ui.min': ['jquery'],
			'RegalCalendar': ['jquery'],
			'jquery.ui.touch-punch.min': ['jquery']
		}
	});
	requirejs(['jquery', 'bootstrap.min', 'underscore', 'jquery.easing.1.3', 'jquery.iconpicker', 'jquery.timepicker', 'jquery.qtip', 'jquery.geocomplete.min', 'jquery-ui.min', 'RegalCalendar', 'jquery.ui.touch-punch.min'], function($) {
		/* Calendar configuration*/
		$('#calendar').RegalCalendar({
			base: 'white',
			color: '#009292',
			editable: false,
			eventsPosition: 'inline',
			itemsPerPage: 2,
			timeFormat: 'hrs'
		});
	});
    </script>
</head>
<body>
    <div id="calendar" class="regalcalendar"></div>
</body>

API

Use API to retrieve useful information about the events

GetEvents Retrieves current day events

GetMonthEvents Retrieves current month events

GetDate Retrieves selected date 

				
<script>
    var events = $('#calendar').RegalCalendar('GetEvents');
</script>
